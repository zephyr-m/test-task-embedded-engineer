Мой подход к реализации регулятора тока

1. Понимание задачи
- Регулятор тока — самый нижний и самый быстрый контур в системе векторного управления.
- Его задача — точное отслеживание задания по току (в первую очередь по Iq).
- От качества работы этого контура напрямую зависит стабильность усилия сжатия протеза.

2. Принцип работы
- Измеряем реальный ток (Id, Iq)
- Сравниваем с заданным значением
- ПИ-регулятор вычисляет необходимое напряжение Ud, Uq
- Выход регулятора ограничивается и передаётся дальше (на SVPWM)

3. Почему ПИ-регулятор
- Пропорциональная часть даёт быстрый отклик
- Интегральная часть убирает статическую ошибку
- Требуется анти-виндап для предотвращения насыщения интегратора

4. План реализации
- Сначала симуляция в Python для понимания поведения
- Затем реализация на C для STM32
- Тестирование на реальном железе (в будущем)

class PIController:
    def init(self, kp: float, ki: float, output_limit: float = 1.0):
        self.kp = kp
        self.ki = ki
        self.output_limit = output_limit

        self.integral = 0.0
        self.prev_error = 0.0
        self.last_output = 0.0

    def update(self, reference: float, measurement: float, dt: float) -> float:
        error = reference - measurement

        # Пропорциональная часть
        p_term = self.kp * error

        # Интегральная часть
        self.integral += self.ki * error * dt

        # Анти-виндап (ограничение интегратора)
        self.integral = max(-self.output_limit, min(self.output_limit, self.integral))

        # Выход регулятора
        output = p_term + self.integral

        # Ограничение выхода
        output = max(-self.output_limit, min(self.output_limit, output))

        self.last_output = output
        self.prev_error = error
        return output

    def reset(self):
        self.integral = 0.0
        self.prev_error = 0.0
