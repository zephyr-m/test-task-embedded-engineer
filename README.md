# Current Loop Controller for PMSM FOC

Тестовое задание Embedded Engineer: ядро регулятора тока для системы векторного управления PMSM-двигателем, рассчитанное на выполнение на STM32 с частотой 20-50 кГц.

## Цель

Реализовать компактный и предсказуемый контур тока для FOC:

- принимать задания `Id_ref`, `Iq_ref` и измеренные токи `Id`, `Iq`;
- вычислять управляющие напряжения `Ud`, `Uq`;
- ограничивать выход по доступному напряжению звена DC;
- защищать интеграторы от windup;
- явно учитывать период дискретизации `Ts`;
- быть пригодным для вызова из прерывания ADC/PWM.

## Выбранный регулятор

Для внутреннего контура тока выбран ПИ-регулятор. В контуре тока PMSM он обычно дает достаточную динамику: пропорциональная часть обеспечивает быстрый отклик, интегральная убирает статическую ошибку, а отсутствие D-составляющей снижает чувствительность к шуму измерения фазных токов.

ПИД для этой задачи не выбран, потому что производная по току на частоте 20-50 кГц усиливает шум ADC, коммутационные пульсации и ошибки синхронизации измерений. Для быстрого электрического контура это чаще ухудшает помехозащищенность, чем дает полезный выигрыш.

## Быстрый запуск симуляции

```bash
python3 simulation/current_loop_sim.py
```

Скрипт моделирует две независимые оси `d/q` как RL-нагрузку и сохраняет CSV-файл `simulation/current_loop_result.csv` с переходным процессом.

## Проверка

```bash
make test
```

Команда выполняет синтаксическую проверку Python, компиляцию C с warning'ами как ошибками, поведенческие Python/C-тесты и демонстрационную симуляцию. Текущий набор включает 15 Python behavioral tests и 17 C behavioral tests.

## Интеграция на STM32

Функция `CurrentLoop_Controller_Update()` должна вызываться с фиксированным периодом из обработчика, синхронизированного с PWM и выборкой ADC. Типовой порядок:

1. ADC/DMA получает фазные токи.
2. Выполняются Clarke/Park-преобразования.
3. Вызывается `CurrentLoop_Controller_Update()`.
4. Выполняются inverse Park/SVPWM.
5. Новые duty-cycle загружаются в таймер PWM.

Код находится в `stm32/Src/current_loop_controller.c`.
