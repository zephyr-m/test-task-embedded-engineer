# Подход к реализации регулятора тока

## Понимание задачи

Регулятор тока является самым быстрым внутренним контуром в FOC. Внешние контуры положения, скорости или усилия формируют задание тока, а текущий контур должен быстро и устойчиво привести реальные `Id` и `Iq` к заданным значениям.

Для PMSM в системе протеза это критично: `Iq` связан с электромагнитным моментом, значит с усилием движения пальца, а `Id` обычно поддерживается около нуля для эффективной работы без лишнего потока.

## Почему ПИ, а не ПИД

Для контура тока выбран ПИ-регулятор:

- `P` быстро реагирует на ошибку тока;
- `I` устраняет статическую ошибку, связанную с сопротивлением обмотки, противо-ЭДС и неточностью модели;
- структура проста и хорошо подходит для жесткого real-time цикла 20-50 кГц.

D-составляющая не используется. Производная от измеренного тока чувствительна к шуму ADC, PWM ripple, задержкам выборки и квантованию. В быстром токовом контуре такая чувствительность может вызвать дрожание напряжения и ухудшить устойчивость. Если требуется улучшать динамику, предпочтительнее использовать feed-forward/decoupling по модели двигателя, а не D-звено.

## Основная идея алгоритма

На каждом шаге:

1. Получить `Id_ref`, `Iq_ref`, `Id_meas`, `Iq_meas`, `Ts`.
2. Посчитать ошибки:
   `err_d = Id_ref - Id_meas`, `err_q = Iq_ref - Iq_meas`.
3. Для каждой оси вычислить предварительный выход ПИ-регулятора.
4. Ограничить итоговый вектор напряжения `Ud/Uq` по доступному `Umax`.
5. Обновить интеграторы с учетом anti-windup.
6. Вернуть `Ud`, `Uq` для inverse Park/SVPWM.

## Anti-windup

В реализации используется условное интегрирование:

- сначала считается насыщенный выход;
- интегратор обновляется только если регулятор не насыщен либо если текущая ошибка выводит регулятор из насыщения;
- интегратор дополнительно ограничивается диапазоном `integrator_min/integrator_max`.

Такой подход прост, детерминирован и хорошо подходит для микроконтроллера. Он не дает интегральной части накапливаться, когда физически доступного напряжения уже не хватает.

## Ограничение выходного сигнала

В FOC важно ограничивать не только `Ud` и `Uq` по отдельности, но и длину вектора напряжения:

```text
sqrt(Ud^2 + Uq^2) <= voltage_limit
```

Если вектор больше доступного лимита, обе компоненты масштабируются с сохранением направления. Это корректнее для SVPWM, чем независимое ограничение каждой оси.

## Дискретизация

Период `Ts` передается явно в `CurrentLoop_Controller_Update()`. Это делает код устойчивым к изменению частоты цикла и упрощает тестирование. Для целевой частоты:

- 20 кГц: `Ts = 50 us`;
- 50 кГц: `Ts = 20 us`.

В реальной системе период должен задаваться таймером PWM и не должен вычисляться через нестабильные задержки основного цикла.
