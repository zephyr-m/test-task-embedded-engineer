# Использование нейросетей

При подготовке решения использовались нейросетевые инструменты как помощник для структурирования материалов, проверки формулировок и генерации черновых вариантов кода. Технические решения были дополнительно отфильтрованы с учетом требований real-time embedded-разработки.

## Использованные инструменты

- ChatGPT/Codex - структурирование репозитория, оформление документации, проверка C/Python-кода.

## Пример удачного промта

```text
Мне нужно подготовить тестовое задание Embedded Engineer:
реализовать ядро CurrentLoop_Controller_Update() для контура тока PMSM FOC на STM32,
частота 20-50 кГц. Помоги выбрать ПИ или ПИД, объяснить выбор,
предложить C-структуры данных, anti-windup, ограничение вектора напряжения
и порядок вызова из PWM/ADC interrupt. Нужен инженерный стиль без маркетинга.
```

## Как использовался результат

Ответы нейросети использовались как черновой материал. В финальное решение вошли только проверенные идеи:

- выбор ПИ-регулятора для внутреннего контура тока;
- условное интегрирование как anti-windup;
- ограничение вектора `Ud/Uq`;
- явная передача `Ts`;
- разделение документации, C-кода и симуляции.
