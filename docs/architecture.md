# Архитектура регулятора

## Место в FOC

Регулятор находится после Park-преобразования и до inverse Park/SVPWM:

```text
Ia/Ib/Ic -> Clarke -> Park -> CurrentLoop_Controller_Update -> inverse Park -> SVPWM -> inverter -> PMSM
```

На вход приходят токи в вращающейся `dq`-системе координат. На выходе формируются напряжения `Ud` и `Uq` в той же системе координат.

## Входы

- `id_ref`, `iq_ref` - задания токов по осям `d` и `q`, A;
- `id_meas`, `iq_meas` - измеренные токи после Clarke/Park, A;
- `ts` - период дискретизации, s;
- параметры регулятора: `kp`, `ki`, пределы интегратора и напряжения.

## Выходы

- `ud`, `uq` - управляющие напряжения в `dq`, V;
- флаги насыщения по осям и по вектору напряжения;
- диагностические значения ошибок и внутренних компонент.

## Состояние

Для каждой оси хранится:

- интегральная составляющая;
- последние значения `p_term`, `i_term`, `output`;
- флаг насыщения.

Контроллер верхнего уровня содержит два таких ПИ-регулятора: `d_axis` и `q_axis`.

## Вызов в real-time цикле

Функция должна вызываться из обработчика, привязанного к таймеру PWM или окончанию ADC-преобразования:

```c
void ADC_PWM_IRQHandler(void)
{
    // 1. Read phase currents from ADC/DMA
    // 2. Clarke/Park transform
    // 3. CurrentLoop_Controller_Update()
    // 4. Inverse Park + SVPWM
    // 5. Update PWM compare registers
}
```

Важно, чтобы `Ts` был постоянным, а измерение тока было синхронизировано с PWM, иначе фаза измерений будет добавлять задержку и шум в контур.

## Численная устойчивость

В коде предусмотрены:

- проверка указателей;
- защита от невалидного `Ts`;
- ограничение `Ts` диапазоном настройки;
- ограничение интегратора;
- ограничение напряжения по модулю вектора;
- отсутствие динамической памяти;
- отсутствие деления на ноль при масштабировании вектора.
